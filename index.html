Protection des données personnelles

Cet outil enregistre surtout des informations techniques sur les ouvrages. Les seules données personnelles possibles sont le nom et le téléphone du gestionnaire, le nom de l'enquêteur et les photos.

Le nom et le téléphone du gestionnaire ne sont enregistrés qu'avec son accord, coché dans la fiche. Ils sont exclus par défaut des exports Excel et QGIS.

Photographiez l'ouvrage, pas les personnes. Évitez les visages reconnaissables, surtout ceux des enfants.

Les données restent sur l'appareil. Protégez le téléphone par un code et ne transmettez les sauvegardes qu'aux personnes autorisées.

Cadre : loi n° 2017-020 sur la protection des données à caractère personnel. Les formalités auprès de l'Autorité de protection des données sont à vérifier avant un déploiement à grande échelle.
